# ECDAT — Enterprise Cryptographic Discovery & Analysis Tool

**SIH 2026 · Problem Statement SIH26164 · NTRO · Blockchain & Cybersecurity**

**Tagline:** Discover. Prove. Simulate. Migrate.

ECDAT is an evidence-backed cryptographic discovery and migration decision-support platform. It inventories cryptographic artefacts, preserves evidence and provenance, builds a cryptographic dependency graph, evaluates quantum risk, estimates migration blast radius, and produces evidence-backed PQC/hybrid migration options.

## Truthfulness rule

A dependency, import, backend, implementation or capability is **not automatically proof of runtime use**. Every claim must carry evidence role, provenance and confidence. Measured results must be generated by the implementation; this package contains no fabricated benchmark scores.
