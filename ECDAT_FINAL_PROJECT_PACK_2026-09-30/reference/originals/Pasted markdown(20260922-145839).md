### Hour 4–8: Dependency & Certificate Scanners
**Goal:** Add dependency and X.509 analysis.

- **Lead:** Backend dev.
- **Dependency scanner:**
  - Parse `requirements.txt`, `package.json`, `pom.xml`, `go.mod`.
  - Map known crypto libs to algorithms (OpenSSL → RSA, ECDSA; BouncyCastle → AES, RSA).

**Deliverable:** Unified findings JSON with ~50 assets from test corpus.

### Hour 8–12: CBOM Generator & Evidence Graph
**Goal:** Convert findings to CycloneDX CBOM and build asset graph.

- **Lead:** Backend dev + data modeler.
- Map findings to CycloneDX `crypto-asset` schema.
- Build a graph (NetworkX) with nodes: Application, Library, Algorithm, Certificate, Protocol.
- Edges: `uses`, `implements`, `protects`, `dependsOn`.
- Store as JSON: `{nodes: [...], edges: [...]}`.

**Deliverable:** `cbom.json` and `graph.json` from test corpus.

---

### Hour 12–16: Quantum Risk Engine (Mosca Monte Carlo)
**Goal:** Implement Layer 1 risk scoring.

- **Lead:** ML/risk dev.
- Implement Monte Carlo simulation:
  ```python
  import numpy as np
  N = 200000
  Tq = np.random.normal(2035, 3, N)  # Q-day distribution
  X = 10  # data lifetime
  Y = 6   # migration time
  Ts = 2026
  Tc = Ts + Y
  f = np.minimum(1, np.maximum(0, (np.minimum(Tq, Tc) - (Tq - X)) / X))
  P_f_gt_0 = np.mean(f > 0)
  E_f = np.mean(f)
  ```
- Compute for each asset based on its type (KEM vs signature vs symmetric).
- Assign risk score: `risk = P_f_gt_0 * 0.4 + E_f * 0.3 + criticality * 0.3` (adjust weights).

**Deliverable:** `risk_scores.json` mapping each asset to risk level (Critical/High/Medium/Low).

### Hour 16–20: PQC Recommendation Engine
**Goal:** Map vulnerable assets to PQC alternatives.

- **Lead:** Crypto researcher.
- Simple rule-based mapping:
  | Current | Primitive | Recommendation | Hybrid Option |
  |---------|-----------|----------------|---------------|
  | RSA-2048 | KEM | ML-KEM-768 | X25519 + ML-KEM-768 |
  | RSA-2048 | Signature | ML-DSA-65 | RSA + ML-DSA-65 |
  | ECDSA P-256 | Signature | ML-DSA-44 | ECDSA + ML-DSA-44 |
  | ECDH | KEM | ML-KEM-768 | X25519 + ML-KEM-768 |
  | AES-128 | Symmetric | AES-256 | — |
  | SHA-256 | Hash | SHA-384 | — |
- Add rationale and performance note (e.g., "ML-DSA signature size ~2.4KB vs ECDSA 64B").

**Deliverable:** `recommendations.json` per asset.
